# 🎲 搖骰子遊戲

單一 HTML 檔的搖骰子遊戲：可設定骰子數量（1～3 粒），內建三種玩法，含 3D 翻轉動畫、合成音效、深色霓虹主題。**零外部資源**，離線雙擊即可玩。

## 快速開始

1. 用瀏覽器（Chrome／Edge／Firefox／Safari）直接雙擊開啟 `dice-game.html`
2. 選擇模式與骰子數量 → 按下「擲骰」

> 不需伺服器、不需網路、不需安裝任何東西。

## 功能一覽

| 功能 | 說明 |
|---|---|
| 骰子數量 | 1～3 粒，所有模式通用，切換立即反映 |
| 純擲骰 | 顯示每粒點數、總和與總和範圍 |
| 猜大小 | 先押大／小再擲骰；含傳統骰寶規則（見下方） |
| 比大小對戰 | 與電腦三局兩勝；平手自動重擲、比分不變 |
| 3D 動畫 | CSS 3D 翻轉震盪落定，多粒依序落下 |
| 音效 | Web Audio 合成搖骰聲與落定聲，可開關（🔊/🔇） |
| 響應式 | 桌機與手機（直／橫）皆可使用 |
| 減少動效 | 系統開啟「減少動效」時自動跳過動畫 |

## 遊戲規則

### 猜大小（隨骰數自動調整）

| 骰數 | 小 | 大 | 特殊 |
|---|---|---|---|
| 1 粒 | 總和 1～3 | 總和 4～6 | — |
| 2 粒 | 總和 2～6 | 總和 8～12 | 總和 7 = 和局（不計勝敗） |
| 3 粒 | 總和 4～10 | 總和 11～17 | 豹子（三粒同點）= 大小通殺，必輸 |

### 比大小對戰

- 玩家與電腦各擲一次，總和高者得 1 分
- 總和相同 = 和局，自動重擲該局（比分不變）
- 先得 2 分者贏得賽事（三局兩勝）
- 戰績與勝率於本次開啟期間累計（重整頁面即重置）

## 技術重點

- **純 Vanilla**：HTML5 + CSS3 + JavaScript，無框架、無建置步驟
- **3D 骰子**：CSS `transform-style: preserve-3d` 六面立方體，點數以 3×3 網格排版
- **動畫**：Web Animations API，`fill: forwards` 保證骰子停在最終面（先算結果、再播動畫）
- **音效**：Web Audio API 即時合成（白噪聲脈衝＋衰減正弦），無音檔
- **隨機性**：`Math.random()`，每粒 1～6 等機率

## 驗收狀態

- 引擎邏輯（大小判定、豹子、和局、對戰勝負）：單元測試 **21/21 PASS**
- AC-1～AC-15 與補充驗收：程式碼審查通過
- 剩餘人工驗證：效能（60fps）、真機測試（iPhone／Android 橫直向）——見 `todolist.md` T38／T39

## 已知限制

- 戰績僅存於記憶體，重整頁面即重置（需求範圍內）
- 不支援多人連線、排行榜、賭注系統（非本版本目標）
